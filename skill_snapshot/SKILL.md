# 材料罗盘 (Materials Compass)

## 这个 skill 做什么

把“材料专业很迷茫”拆成一个可执行的决策：

1. 判断用户更适合 **工艺/工程**、**物理/机理**，还是 **交叉方向**；
2. 给出 3–5 所考研目标院校（冲/稳/保），每所附初试科目提示与核验动作；
3. 给出 3–5 个真实岗位样本，说明学历门槛、城市和技能要求；
4. 生成未来 12 个月行动表；
5. 所有结论附来源与 `last_verified` 日期。

## 核心原则

- **给选项，不给判决**：输出冲/稳/保，不输出“你必须学 X”。
- **可核验**：每条学校/岗位建议都有来源链接和核验步骤。
- **承认时效**：招生目录、导师、岗位每年变化；数据超过 12 个月要标灰。
- **不承诺**：不承诺薪资、上岸、就业；薪资只给样本区间。
- **保留非共识选项**：本校保底、科研院所、军工院所、企业联培至少出现一个。

## 工作流

### Step 1：收集画像

先检查用户是否已经给出以下信息。缺什么问什么，但**一次最多问 6 个问题**，不要逐条盘问。

1. 学校、专业、年级（例：中国矿业大学，材料科学与工程，大二）
2. 数学自评 1–5；能否接受数学一
3. 更喜欢动手做工艺，还是推导机理？各打 1–5 分
4. 目标地区：长三角 / 北京 / 西安 / 成渝 / 珠三角 / 不限
5. 学历目标：本科就业 / 硕士就业 / 读博
6. 风险偏好：冲名校 / 稳就业 / 先保底

可选：感兴趣的关键词（增材、表面、半导体、显示、封装、新能源……）。

如果用户拒绝回答，使用默认值并在报告开头写明假设：

- 数学 3，动手 3，理论 3，地区不限，硕士就业，稳。

### Step 2：读取参考

按需读取，不要一次全读：

- `references/directions.md`：三条 track 的定义、课程、岗位族。
- `references/questionnaire.md`：问题措辞与打分锚点。
- `references/school-map.md`：院校/平台地图与选择逻辑。
- `references/jobs.md`：岗位样本与解读。
- `references/sources.md`：来源清单与可信度说明。

机器可读数据在 `references/data/*.json`。

### Step 3：计算匹配

把画像写成临时 JSON（参考 `references/profile.example.json`）。**所有相对路径以本 skill 目录为基准**；如果当前目录不确定，先用绝对路径找到 `SKILL.md` 所在目录，再执行：

```bash
python <skill-dir>/scripts/score.py \
  --profile <work-dir>/profile.json \
  --data-dir <skill-dir>/references/data \
  --out <work-dir>/score.json
```

读取 `score.json`。如果 Python 不可用，按 `scripts/score.py` 里的同一公式手算，并在报告里说明。

### Step 4：生成报告

使用 `references/report-template.md` 的结构。可以运行：

```bash
python <skill-dir>/scripts/render_report.py \
  --profile <work-dir>/profile.json \
  --score <work-dir>/score.json \
  --template <skill-dir>/references/report-template.md \
  --out <work-dir>/report.md
```

然后基于 `report.md` 补充 2–3 句针对用户的具体解释。不要只贴模板。

每所学校的报告行必须同时给出 **学院官网** 和 **研招网/研究生院** 两个入口；这两个链接来自数据里的 `official_url` 和 `grad_url`。它们是让用户自己核验招生目录的最短路径。

### Step 5：质量检查

输出前逐条检查：

- [ ] 是否有 3 条 track 的对比，而不是只推一条？
- [ ] 是否有 3–5 所学校，且覆盖冲/稳/保？
- [ ] 每所学校是否有学院官网 + 研招网入口？
- [ ] 每所学校是否写了“去查什么”（招生目录年份、导师、复试）？
- [ ] 岗位薪资是否标注为“样本”，而不是平均值？
- [ ] 是否至少有一个非共识选项？
- [ ] 是否写明数据时效和“以当年招生目录为准”？
- [ ] 是否避免了“保证上岸/保证薪资”的表达？

## 三条 track 的快速定义

- **工艺/工程**：把材料稳定做出来。关键词：增材、焊接、激光熔覆、热喷涂、涂层、封装、失效分析。适合喜欢动手、接受现场、就业导向的人。
- **物理/机理**：解释材料为什么这样。关键词：半导体物理、固体物理、薄膜、缺陷、第一性原理、表征。适合数学强、喜欢推导、接受读博的人。
- **交叉**：用表面工程/材料加工解决电子材料问题。关键词：先进封装、CMP、功率器件封装、半导体设备零部件涂层。适合两者都感兴趣、想保留选择权的人。

## 常见误区

- 把“物理”当成“更高级”：物理侧论文周期长、岗位窄，读博比例高。
- 把“工艺”当成“没技术”：高水平工艺需要传热、流体、凝固、界面、统计能力。
- 只看学校牌子，不看实验室有没有中试线/洁净室。
- 用“材料硕士平均年薪”做决策：样本差异极大，必须看城市、行业、岗位。

## 数据维护

- `last_verified` 超过 12 个月：报告中标注“需重新核验”。
- 新增学校/岗位时，必须填 `source` 和 `last_verified`。
- 本校保底用用户填写的学校动态生成，不要把某一所学校硬编码给所有人；数据里的 `home_school` 只是示例。
- 不把招聘网站的薪资当作统计均值。
